# MachineBridge coding-agent skills

These skills are small, repository-specific instructions for coding agents working on MachineBridge.

- `protocol/SKILL.md` — protocol compatibility and validation rules
- `pty/SKILL.md` — safe PTY lifecycle changes
- `security/SKILL.md` — authentication, authorization and secret-handling rules
- `testing/SKILL.md` — test and verification expectations

When modifying a subsystem, read its skill before changing code.
